## Known limitations for 0.1.0

These are shipped-and-documented gaps, not blockers. Full detail in
`docs/dogfood-notes.md`.

- **Lexical retrieval only.** `vector-embedded`, `vector-pgvector`,
  `vector-hosted`, `graph`, and `hybrid` are real `RetrievalAdapter` classes
  whose every method throws `NotImplementedError` pointing at the phase-8 index
  checkpoint (`src/retrieval/not-implemented.ts`, `src/retrieval/stubs.ts`).
- **The MCP server is a template, not a running service.**
  `templates/mcp-server/` renders a local stdio server on request. No hosted or
  remote server, no auth, no deployment.
- **No remote/hosted server layer at all.** 0.1.0 is a repo plus scripts plus the
  interview.
- **`resume` is minimal.** It re-opens a saved interview and asks only newly
  relevant questions; it does not deeply diff a changed question bank.
- **Preflight does not scan `.agents/skills/`.** Its skill scan checks `skills/`
  and `.claude/skills/` only, so an SME implemented as a skill under
  `.agents/skills/` reads as "router / SME agent: none".
- **A few interview questions are asked unconditionally.** `pre.overlap` and
  `pre.probe_result` (Act 0) fire with prompts that assume a positive detection
  even when preflight found nothing; `ask_if` is not yet wired to
  preflight-derived facts. "Decide later" / "continue" are safe answers.
- **Custom domains and free-text namespaces generate TODO stubs, never guesses**
  (quality-bar Q11) — the operator fills in the description and keywords before a
  custom domain agent is useful.
- **Idempotent `init` re-run reports two phantom collisions** (`index.lock`,
  `manifest.yaml`) — cosmetic; the files are regenerated at the end of the run
  and no data is lost.
